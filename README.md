# Campus Placement Intelligence & Employability Analytics
## Project Overview
This project is an end-to-end Data Analyst portfolio project focused on student placement analytics, employability insights, internship impact analysis, and risk assessment using SQL and Power BI.

## Tools & Technologies Used
* Power BI
* SQL (MySQL Workbench)
* DAX
* Power Query
* Excel

## Key Features
* Executive Placement Dashboard
* Skill Gap Analysis
* Internship Impact Analysis
* Student Risk & Placement Readiness Analysis
* KPI Cards and Interactive Visuals
* SQL Business Insight Queries
* Employability Scoring Logic

## Business Insights
* Identified departments with low placement rates
* Analyzed internship impact on salary packages
* Evaluated technical and communication skill gaps
* Created student placement risk categorization

* Power BI Dashboard (.pbix)

* Dataset CSV Files
